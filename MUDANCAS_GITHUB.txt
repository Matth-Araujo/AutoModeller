AutoModeller - Registro de Mudanças / Release Notes para o GitHub
================================================================================

Resumo das Modificações Recentes:

1. SEGURANÇA E CONFORMIDADE DE LICENÇA (Purge da chave MODELIRANJE)
--------------------------------------------------------------------------------
- Remoção definitiva de todas as ocorrências de chave de licença em texto puro
  (hardcoded) do código-fonte, configurações, Dockerfiles e documentações.
- Implementação de injeção segura da licença via variável de ambiente KEY_MODELLER.
- Criação do arquivo '.env.example' com instruções para que cada pesquisador
  registre sua chave acadêmica gratuita no portal oficial do Sali Lab
  (https://salilab.org/modeller/registration.html).
- Criação e configuração de '.gitignore' protegendo o arquivo '.env', arquivos
  de compilação de bytecode (*.pyc), banco local sqlite3 e diretórios de mídia temporários.
- Desvinculação dos arquivos pycache e sqlite3 previamente rastreados no git.

2. FLUXO DE MODELAGEM: RÁPIDA (1-CLICK) VS. COM PARÂMETROS
--------------------------------------------------------------------------------
- Formulário de criação de experimento atualizado com seletor interativo em cards:
  * Modelagem Rápida (1-Click Automático): pipeline 100% autônoma, ideal para
    obtenção ágil de modelos utilizando o molde de maior identidade de sequência.
  * Modelagem com Parâmetros: fluxo guiado em duas etapas, permitindo inspecionar
    templates homólogos antes de disparar a construção dos modelos 3D.
- Opção para definir o número de modelos 3D a serem construídos (1 a 10).
- Opção para ativar ou desativar o refinamento de loop com definição de resíduo
  inicial e final.

3. PÁGINA DEDICADA DE SELEÇÃO INTERATIVA DE TEMPLATES
--------------------------------------------------------------------------------
- Nova rota e template ('/experiments/<uuid>/select-template/'):
  * Executa a busca inicial de moldes homólogos via FindTemplatesStep no banco pdb_95.
  * Pausa controlada da execução com status 'AWAITING_TEMPLATE'.
  * Tabela com todos os candidatos homólogos identificados, exibindo código PDB,
    cadeia, barra de progresso com porcentagem de identidade de sequência e link
    direto para visualização na RCSB PDB.
  * Opção para selecionar um dos moldes da lista ou inserir manualmente um código
    PDB externo e cadeia alternativa.
  * Ajuste de parâmetros de modelagem diretamente na etapa de seleção.
  * Ao confirmar, a pipeline retoma assincronamente a modelagem 3D (AlignStep,
    BuildModelStep, perfis energéticos DOPE e refinamento de loops).

4. ABA DE ALINHAMENTO 2D (AlignStep) FUNCIONAL E INTERATIVA
--------------------------------------------------------------------------------
- Na página de detalhes do experimento, a aba de Alinhamento 2D foi completamente
  reformulada para apresentar os resultados reais gerados pelo Modeller:
  * Resumo com identificação do alvo, molde e contador de resíduos idênticos conservados (*).
  * Alternador de visualização entre formato PAP (com numeração de posições, gaps e
    marcação de conservação) e formato PIR clássico (ali.ali).
  * Botões dedicados para download direto dos arquivos 'ali.pap' e 'ali.ali'.
  * Atualização assíncrona em tempo real via AJAX: assim que o AlignStep conclui o
    alinhamento, o conteúdo é exibido instantaneamente na tela sem necessidade de recarregar.

5. TESTES E QUALIDADE DE CÓDIGO
--------------------------------------------------------------------------------
- Suíte completa de testes unitários e de integração utilizando should-dsl
  expandida para 19 testes automatizados (100% de aprovação).
- Testes cobrindo redirecionamento de modos, seleção de molde, parsing de arquivos
  de alinhamento 2D e integridade da API JSON.
